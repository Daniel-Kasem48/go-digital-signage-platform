# Dashboard User Guide

## Who This Is For
This guide is for business users and operators who manage screen content from the dashboard.

## What You Can Do In The Dashboard
- Upload and organize media content
- Build playlists for campaigns
- Assign playlists to channels
- Schedule what plays and when
- Publish updates to screens
- Track screen and campaign status

## Main Areas In The UI
- **Overview**: High-level business snapshot (counts, activity, health)
- **Contents**: Upload and manage media assets
- **Playlists**: Group content in the order you want it shown
- **Layouts**: Define how content appears on screen regions
- **Channels**: Create campaign streams for one or more screens
- **Schedules**: Control dates, days, and time windows
- **Devices**: Check screen status and assignment

## Standard Operating Flow
Use this order for every new campaign:

1. Upload content
2. Create or select layout
3. Create playlist
4. Add content to playlist
5. Create or select channel
6. Schedule channel timing
7. Publish to target devices
8. Monitor results

## Step-by-Step (UI)

### 1. Upload Content
Go to **Contents**:
- Click **Upload**
- Enter a clear content name
- Choose content type
- Select file
- Confirm upload

Business tip:
- Use campaign-friendly names like `Ramadan_Offer_Week1_Hero`.

### 2. Prepare Layout
Go to **Layouts**:
- Create a new layout or reuse an existing one
- Save with a descriptive name


### 3. Build Playlist
Go to **Playlists**:
- Create playlist
- Select layout
- Add content items
- Set item order and duration


### 4. Set Up Channel
Go to **Channels**:
- Create a channel for the campaign or audience
- Open channel details
- Confirm intended target devices

Business tip:
- Use channel names by business purpose, not by person name.

### 5. Schedule Playback
Go to **Schedules**:
- Select channel
- Add day/time windows
- Assign playlist
- Save schedule

Business tip:
- Always verify start/end times before publishing.

### 6. Publish
From **Channel details**:
- Select target devices
- Click **Publish**
